## GitHub 작업 원칙

- 사용자는 작업 결과와 제작 자료를 GitHub에 계속 반영해 달라고 요청했다.
- 의미 있는 작업 단위가 완성되면 해당 프로젝트의 연결된 GitHub 저장소에 변경을 반영하고, 커밋 및 업로드 결과를 확인해 알린다.
- 업로드 대상은 https://github.com/dlaltnr77krmoney-hub/- 저장소의 songdo-maengkkongi-ar/ 폴더이다. 기존 소개 페이지는 유지하며 이 폴더에 프로젝트 자료를 추가한다.
- 배포와 GitHub 업로드는 별도 작업이다. 자료 업로드만으로 웹사이트 공개 배포를 완료했다고 말하지 않는다.
- 설치 라이브러리(node_modules), 패키지 캐시, 임시 렌더 파일, 개인 셀카와 인증정보는 업로드 대상에서 제외한다.

## 현재 확정한 체험

- 안내 게가 진행하는 맹꽁이 찾기 퀴즈 5문제.
- 번호별 양서류의 모습과 실제 울음소리를 함께 보여준다. 사용자의 새 요청에 따라 마지막 문제는 3D 그림을 숨기고 실제 맹꽁이 울음소리만 듣고 답을 고르는 고난도 복습으로 바꿨다.
- 동물은 손가락으로 회전하고 두 손가락으로 확대·축소한다. 화면에는 짧은 안내, 소리 다시 듣기, 다음 친구 등 최소한의 요소만 둔다.
- 안내 게는 눈자루 접기와 내밀기, 거품, 화면을 향한 장난 물총으로 반응한다.
- 게의 자절은 보호 행동을 함께 배우는 문제로 포함한다. 오답에 따라 다리가 떨어지는 연출은 사용하지 않는다.
- 겨울잠 돕기 미션은 사용자가 제외하기로 결정했다.
- 완료 후 앞 카메라 셀카에서 맹꽁이 캐릭터가 울음주머니를 부풀리고, 기념사진 한 장을 저장한다.
- 선택형 오늘의 순위. 자유 관찰과 설명·연출·사진 촬영 시간은 경쟁 시간에서 제외한다.
- 브랜드 표기안: 상상아트 | 기획·제작 이미숙.

## 현재 제작 결과

`assets/crab/`

- `sangsang-art-longleg-crab.glb`: 웹용 경량 모델, 3,444,972 bytes, 42,177 triangles.
- `sangsang-art-longleg-crab-detail.glb`: 상세 모델, 10,774,832 bytes, 117,321 triangles.
- 원본의 전통 문양·보석 텍스처를 유지하며 걷는 다리 여덟 개를 늘렸다. TV 형태 받침대는 제외했다.
- 정적 모델이다. 뼈대, 눈·집게발·다리 애니메이션은 아직 없다.
- 두 GLB의 형식 검사: 오류 0, 경고 0. 로컬 Three.js 뷰어에서 경량본 표시와 회전 확인.
- 실제 휴대전화 WebAR 성능은 아직 검증하지 않았다.
- `preview/index.html`은 로컬 검토용이며 `tools/node_modules/three`에 의존한다. 공개 배포된 사이트가 아니다.

## 참고 자료

- 기존 짝다리 웹배포 v5: 앞 카메라 요청, 얼굴 추적, 3D 표시, 사진 합성·저장·공유 구조를 코드로 확인했다.
- 짝다리의 얼굴 기반 머리 배치와 맹꽁이의 어깨 추적은 같은 기능이 아니며, 어깨 추적은 별도 구현이 필요하다.

## 2026-09-26 제작 시작 및 첫 실행본

- 사용자가 한복 없는 7번 캐릭터를 선택하고 시작을 요청했다.
- 관찰 친구는 맹꽁이·두꺼비·옴개구리로 구성했다. 셀카는 귀여운 7번을 기준으로 한다.
- 사용자가 발의 정확성을 질문했다. 앞발마다 4개, 뒷발마다 5개 발가락과 뒷발 부분 물갈퀴를 모델에 구성했다.
- app/에 관찰·퀴즈 5개·오답 효과·결과·순위·셀카 코드를 추가했다. server/는 Python 표준 라이브러리+SQLite로 공통 기록을 처리한다.
- 겨울잠 미션 제외. 관찰형 3D와 셀카용 창작 캐릭터를 구분한다.
- app/assets/models/에 관찰 3종 및 셀카 GLB 1개를 추가했다. 모두 형식 오류·경고 0이다.
- 지금 모델은 직접 구성한 형태 시제품이다. 선택한 그림을 정밀하게 변환한 최종 3D나 실제 개체 스캔은 아니다. 생태·조형 검수 후 보정해야 한다.
- 게 눈자루·집게발 애니메이션은 미구현이다. 화면 거품·물방울 효과부터 연결했다.
- 브라우저에서 관찰부터 5문제·결과·셀카 시작 화면까지 확인했다. 휴대폰에서는 번호를 눌러 한 모델씩 크게 본다.
- 서버 통합검사 2개 통과. 실제 휴대폰의 어깨 추적·촬영 저장·음원 재생과 종 확인·현장 성능은 미검증이다.
- 실행법, 배포 조건, 기록 삭제 범위 및 남은 작업은 README.md, 근거·라이선스는 docs/SOURCES.md에 기록했다.

## 관객 화면의 정답 노출 보정

- 사용자는 7번 타깃 그림을 퀴즈 전에 관객에게 보여주면 정답을 알려주는 문제를 지적했다.
- 시작 화면에서 7번 타깃 이미지를 제거하고 안내 게와 물음표 연출로 바꿨다.
- 타깃 그림과 3D 비교는 제작 검토 전용 URL인 `app/model-review.html`에서 확인한다. 체험 화면에는 이 링크를 넣지 않는다.
- 셀카용 7번 캐릭터는 퀴즈 완료 뒤에 등장한다.

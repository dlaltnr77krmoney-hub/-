# 송도 생태 AR 체험 — 상상아트

기획·제작: 이미숙 · 상상아트

## GitHub 작업 원칙

- 사용자는 작업 결과와 제작 자료를 GitHub에 계속 반영해 달라고 요청했다.
- 의미 있는 작업 단위가 완성되면 해당 프로젝트의 연결된 GitHub 저장소에 변경을 반영하고, 커밋 및 업로드 결과를 확인해 알린다.
- 업로드 대상은 https://github.com/dlaltnr77krmoney-hub/- 저장소의 songdo-maengkkongi-ar/ 폴더이다. 기존 소개 페이지는 유지하며 이 폴더에 프로젝트 자료를 추가한다.
- 배포와 GitHub 업로드는 별도 작업이다. 자료 업로드만으로 웹사이트 공개 배포를 완료했다고 말하지 않는다.
- 설치 라이브러리(node_modules), 패키지 캐시, 임시 렌더 파일, 개인 셀카와 인증정보는 업로드 대상에서 제외한다.

## 현재 확정한 체험

- 안내 게가 진행하는 맹꽁이 찾기 퀴즈 5문제.
- 번호별 양서류의 모습과 실제 울음소리를 함께 보여준다. 소리만 듣는 고난도 문제로 만들지 않는다.
- 동물은 손가락으로 회전하고 두 손가락으로 확대·축소한다. 화면에는 짧은 안내, 소리 다시 듣기, 다음 친구 등 최소한의 요소만 둔다.
- 안내 게는 눈자루 접기와 내밀기, 거품, 화면을 향한 장난 물총으로 반응한다.
- 게의 자절은 보호 행동을 함께 배우는 문제로 포함한다. 오답에 따라 다리가 떨어지는 연출은 사용하지 않는다.
- 겨울잠 돕기 미션은 사용자가 제외하기로 결정했다.
- 완료 후 앞 카메라 셀카에서 맹꽁이 캐릭터가 울음주머니를 부풀리고, 기념사진 한 장을 저장한다.
- 선택형 오늘의 순위. 자유 관찰과 설명·연출·사진 촬영 시간은 경쟁 시간에서 제외한다.
- 브랜드 표기안: 상상아트 | 기획·제작 이미숙.

## 현재 제작 결과

`assets/crab/`

- `sangsang-art-longleg-crab.glb`: 웹용 경량 모델, 3,444,972 bytes, 42,177 triangles.
- `sangsang-art-longleg-crab-detail.glb`: 상세 모델, 10,774,832 bytes, 117,321 triangles.
- 원본의 전통 문양·보석 텍스처를 유지하며 걷는 다리 여덟 개를 늘렸다. TV 형태 받침대는 제외했다.
- 정적 모델이다. 뼈대, 눈·집게발·다리 애니메이션은 아직 없다.
- 두 GLB의 형식 검사: 오류 0, 경고 0. 로컬 Three.js 뷰어에서 경량본 표시와 회전 확인.
- 실제 휴대전화 WebAR 성능은 아직 검증하지 않았다.
- `preview/index.html`은 로컬 검토용이며 `tools/node_modules/three`에 의존한다. 공개 배포된 사이트가 아니다.

# 현장 AR 인식 대상 제안

## 추천 구성

- **체험 장소:** 포항 송도솔밭도시숲의 일반 산책로 또는 입구. 맹꽁이 서식처 안으로 관객을 유도하지 않는다.
- **카메라 인식 대상:** 산책로 입구의 고정 안내판에 붙일 별도 `송도 생태 탐험` 표식. 설치·부착 가능 여부를 운영 주체와 확인한다. 시설물 설치가 어렵다면 행사 때 허용된 장소에 세운 이동식 안내판을 사용한다.
- **그림 내용:** 송도솔밭을 떠올리게 하는 소나무·길·바다 요소. 맹꽁이 모습이나 이름을 그리지 않아 퀴즈 정답을 미리 알려주지 않는다.
- **시작 방법:** QR은 웹페이지 접속용, 표식 이미지는 카메라가 위치와 방향을 잡는 용도. 둘을 구분해 배치한다.
- **실패 대안:** 현장 햇빛이나 기기 성능 때문에 이미지 인식이 안 되면 버튼으로 관찰 화면을 시작할 수 있게 한다.

## 세 후보 비교

| 후보 | 쓰임 | 판단 |
|---|---|---|
| 실제 맹꽁이 서식처 사진·현장 | 교육 이야기의 배경 | 생김새와 빛, 계절이 변하고 접근을 유도하므로 인식 대상으로 권하지 않음 |
| 송도 소나무 솔밭 전체 풍경 | 체험 장소·배경 | 송도와 맹꽁이 이야기에 가장 알맞지만 소나무의 반복 무늬는 이미지 인식에 불리함 |
| 송도 건물 | 장소 안내·후보 표식 | 고유한 벽화나 고정 디자인이 있으면 인식 가능. 맹꽁이 서식 이야기와는 거리가 있음 |

## 아직 정해야 할 것

1. 사용할 **실제 안내판/표식의 위치와 정면 사진**. 현재는 확정된 현장 인식 이미지가 없다.
2. 설치 허가와 햇빛·그늘에서의 인식 확인.
3. 사진 또는 전용 표식이 정해진 뒤 WebAR 이미지 추적을 구현하고 현장에서 시험. **현재 첫 실행본에는 장소 이미지 추적 기능이 없다.**

- [Zappar 이미지 추적 가이드](https://docs.zap.works/mattercraft/augmented-reality/image-tracking/best-practices/): 반복 무늬, 반사 표면, 조명 조건을 고려하도록 권고.

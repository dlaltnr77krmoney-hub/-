# 현장 AR 인식 대상 제안

## 2026-09-26 전시 장소 사진을 본 뒤 수정한 추천 구성

- **체험 장소:** 사용자가 지도에서 초록색으로 표시한 전시 구역. 항공사진에서 포장 공간과 건물은 보이나, 실내 동선·벽면·설치 가능 위치는 알 수 없다.
- **카메라 인식 대상:** 전시장에 세울 무광 인쇄 표식. 건물 외벽이나 송도솔밭 풍경 자체를 인식 대상으로 정하지 않는다. A3 인쇄물부터 가까운 거리에서 시험하고, 관객 동선과 거리 때문에 작으면 A2로 늘린다.
- **표식 그림:** [전시용 시안](../app/assets/exhibition-marker-draft.svg). 소나무·바다를 나타내되 맹꽁이 모습이나 이름은 넣지 않아 퀴즈 정답을 알려주지 않는다. 비대칭의 고유한 형태와 밝고 어두운 차이를 사용했다. 이미지 추적 성능은 아직 측정하지 않았다.
- **시작 방법:** QR은 웹페이지 접속용으로 표식 밖의 별도 안내에 둔다. 표식은 카메라 화면에 비추어 인식한다. 관객이 셔터를 눌러 사진을 저장하거나 업로드하는 방식은 필요하지 않다.
- **실패 대안:** 조명·반사·기기 성능으로 인식이 안 되면 버튼으로 관찰 화면을 시작할 수 있게 한다.

## 세 후보 비교

| 후보 | 쓰임 | 판단 |
|---|---|---|
| 실제 맹꽁이 서식처 사진·현장 | 교육 이야기의 배경 | 생김새와 빛, 계절이 변하고 접근을 유도하므로 인식 대상으로 권하지 않음 |
| 송도 소나무 솔밭 전체 풍경 | 그림의 소재 | 소나무의 반복 무늬와 햇빛 변화가 이미지 인식에 불리함 |
| 송도 건물 | 장소 안내 | 전시장 주변의 벽면·건물 사진은 인식 가능성을 현장에서 별도 평가해야 함 |
| 전시장에 세운 무광 그림 표식 | AR 인식 대상 | 위치·크기·조명을 관리할 수 있고 퀴즈 정답도 숨길 수 있어 우선 추천 |

## 아직 정해야 할 것

1. 전시장 안에서 표식을 세워도 되는 위치와 관객이 카메라를 비출 거리 확인. 항공사진만으로는 이를 판단할 수 없다.
2. 인쇄한 시안을 실제 조명에서 촬영하고 이미지 인식 특징점·거리·각도 테스트. 필요하면 디자인을 고친다.
3. 이미지 추적 WebAR와 인식 실패 시 시작 버튼 연결. **현재 첫 실행본에는 장소 이미지 추적 기능이 없다.** 시안만 인쇄해도 아직 AR이 실행되지는 않는다.

## 근거

- [포항시 송도해수욕장 안내](https://pohang.go.kr/dept/contents.do?mid=0305010000): 송도솔밭을 주변 관광 자원으로 소개.
- [2026년 송도솔밭 방제 보도](https://mobile.newsis.com/view/NISX20260616_0003671693): 시 방제 계획에서 솔밭의 맹꽁이 서식처를 제외한다고 설명.
- [MindAR 이미지 타깃 가이드](https://www.mindar.org/how-to-choose-a-good-target-image-for-tracking-in-ar-part-3/): 특징점이 충분하고 고르게 분포한 고대비 이미지, 반복 무늬 회피 권고.
- [Zappar 이미지 추적 가이드](https://docs.zap.works/mattercraft/augmented-reality/image-tracking/best-practices/): 반복 무늬, 반사 표면, 조명 조건을 고려하도록 권고.

## 제작·수정할 내용

1. [ ] 관찰형 맹꽁이·두꺼비·옴개구리 GLB에 종별 형태와 피부 무늬를 검토한 이미지 텍스처를 적용한다. 귀여운 셀카용 7번 맹꽁이는 별도 캐릭터 텍스처로 다듬는다. 현재 네 GLB 모두 이미지/텍스처가 0개이며 재질 색만 사용한다. 휴대폰 로딩 속도와 용량을 함께 확인한다.
2. [ ] 첫 그림의 알처럼 보이는 구체·깊은 동굴을 제거하고, 지표 가까운 낙엽·흙 사이에 맹꽁이를 그린 시안을 검토한다. `docs/concepts/songdo-pine-shallow-maeng-v3.png`는 비교 시안이며 공개 포스터에는 미적용이다. 특정 송도 지점의 실제 서식 위치나 고정된 굴 깊이로 설명하지 않는다.
3. [ ] 솔밭·바다·멀리 보이는 포스코 풍경과 디지털 요소가 함께 보이도록 포스터를 단순화한다. 맹꽁이가 그림에 보이면 `솔밭 아래 누가 있을까요?` 문구와 찾기 미션의 연결을 수정한다.
4. [ ] 퀴즈와 셀카 사이의 디지털 소나기 장면을 짧게 설계한다. 비·일시적인 물웅덩이·수컷 울음주머니 표현은 생태 근거에 맞춘다. 셀카용 연잎 우산은 창작 연출 여부를 아직 결정하지 않았다.
5. [ ] 손바닥 셀카의 접촉 그림자와 맹꽁이 눈·몸 비율을 다듬는다. 자동 손 인식 대신 현재 터치 배치를 유지한다.
6. [ ] 실제 휴대폰에서 소리 겹침, 앞 카메라, 사진 저장, 모델 성능, 포스터 가독성을 확인한다. 이미지 인식 AR은 현재 미구현이므로 실제 표식 인식이 필요하면 별도 구현·현장 검증한다.

## 배포·저장소 전환 순서

1. [ ] 사용자에게 기존 Netlify 사이트가 있으면 그 주소를 받는다. 아직 없다면 새 Netlify 사이트를 만들고 주소를 확보한다. 정적 체험의 게시 위치와 관리 방식을 확인한다.
2. [ ] Netlify 주소에서 휴대폰 카메라·소리·사진 저장을 확인하고, 포스터 QR을 새 주소로 바꾼다. 주소를 바꾸기 전 제작한 QR은 기존 GitHub Pages 체험으로 연결된다.
3. [ ] 사용자가 최종적으로 오케이하면 GitHub 저장소를 비공개로 전환한다. 현재 `dlaltnr77krmoney-hub/-` 저장소에는 맹꽁이 프로젝트 외 소개 페이지도 있으므로, 저장소 전체를 비공개로 할지 프로젝트를 전용 비공개 저장소로 분리할지 영향 범위를 먼저 확인한다.
4. [ ] Netlify에 게시한 정적 HTML·JavaScript·모델은 웹 방문자가 받을 수 있다는 점을 전제로 공개 파일을 선별한다. GitHub Pages는 GitHub Free에서 저장소를 비공개로 바꾸면 게시가 중단되므로 새 QR 배포를 먼저 마친다.
5. [ ] 공통 순위는 현재 GitHub Pages 공개 연습판에 없다. Netlify에 정적 파일만 게시해도 공통 순위는 생기지 않으므로 별도 데이터 저장 기능이 필요한지 결정한다.

# 송도 맹꽁이 AR

**상상아트 | 기획·제작 이미숙**

포항 송도의 자연과 캐릭터를 활용하는 관광·생태교육 웹 체험 프로젝트입니다.
이 폴더는 기획과 제작 결과를 기록하는 공간입니다. 전체 퀴즈·AR 서비스는 아직 완성되지 않았습니다.

## 현재 결과물

한국적인 보석·전통 문양을 유지하면서 걷는 다리 여덟 개를 늘린 안내 게 모델입니다.

| 파일 | 용도 | 크기 | 삼각형 수 |
| --- | --- | --- | --- |
| [웹용 GLB](assets/crab/sangsang-art-longleg-crab.glb) | 휴대전화 웹 체험에 우선 사용 | 약 3.44 MB | 42,177 |
| [상세 GLB](assets/crab/sangsang-art-longleg-crab-detail.glb) | 자세한 형태·텍스처 확인 | 약 10.77 MB | 117,321 |

- 텍스처는 GLB에 내장되어 있습니다.
- TV 형태 받침대는 제외했습니다. 원본 파일은 수정하지 않았습니다.
- 현재는 **정적 모델**입니다. 눈·집게발·다리 움직임을 위한 뼈대와 애니메이션은 포함하지 않습니다.
- 기존 UV를 유지하므로 일부 다리 문양도 길게 변형되었습니다.
- 두 파일 모두 glTF Validator 오류 0, 경고 0입니다.
- 로컬 Three.js 화면에서 경량본의 표시와 회전을 확인했습니다. 실제 휴대전화 WebAR 성능은 미검증입니다.

## 기획한 체험 흐름

안내 게 등장 → 번호별 동물의 모습과 실제 소리 관찰 → 퀴즈 5개 → 결과·선택형 순위 → 맹꽁이 셀카 한 컷 → 저장.

- 동물을 손가락으로 회전하고 확대·축소합니다.
- 안내 게의 눈자루, 거품, 장난 물총을 활용합니다.
- 게의 자절은 보호 행동과 함께 배우는 문제로 다룹니다.
- 겨울잠 돕기 미션은 제외했습니다.
- 셀카는 앞 카메라로 시작하고, 맹꽁이의 울음주머니가 부푸는 연출을 계획했습니다.
- 학습·자유 관찰 시간은 순위 측정에서 제외합니다.

상세 결정 사항은 [기획 기록](docs/PROJECT_NOTES.md)에 있습니다.

## 3D 미리보기 실행

Node.js와 pnpm을 설치한 환경에서 이 폴더를 기준으로 실행합니다.

```sh
pnpm --dir tools install --frozen-lockfile
python -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8766/preview/`를 엽니다.
미리보기는 로컬 검토용이며, 자료 업로드 자체가 웹사이트 배포를 의미하지는 않습니다.

## 원본에서 모델 다시 만들기

원본 `Meshy_AI_Jeweled_Dream_Crab_0923015551_texture.glb`는 이 폴더에 포함하지 않았습니다.
원본이 있는 환경에서 실행하면 `assets/crab/`의 생성 파일을 갱신합니다.

```sh
node tools/build-crab.mjs "/path/to/Meshy_AI_Jeweled_Dream_Crab_0923015551_texture.glb"
```

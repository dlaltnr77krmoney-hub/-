# 송도 맹꽁이 AR

**상상아트 | 기획·제작 이미숙**

관찰 → 퀴즈 5개 → 결과·선택형 순위 → 어깨 위 맹꽁이 셀카로 이어지는 **첫 실행 시제품**입니다. 선택한 한복 없는 7번 캐릭터를 기준으로 진행합니다. 공개 운영용 완성본은 아닙니다.

## 실행

Python 3.11 이상이 설치된 환경에서 이 폴더를 기준으로 실행합니다. 별도 Python 패키지 설치는 필요하지 않습니다.

```sh
python server/server.py
```

- 체험: `http://127.0.0.1:8767/`
- 3D 형태 검토·GLB 다운로드: `http://127.0.0.1:8767/model-review.html`
- 타깃 그림: `http://127.0.0.1:8767/assets/mascot-reference.png` (한복 없는 7번)
- 종료: 실행한 터미널에서 Ctrl+C

위 주소는 실행한 컴퓨터에서만 열립니다. 다른 휴대폰의 카메라를 사용하려면 HTTPS 호스팅이 필요합니다. 서버는 기본적으로 로컬 주소에만 바인딩됩니다.

## 들어간 기능

- 맹꽁이·두꺼비·옴개구리의 3D 회전, 확대·축소, 특징 비교
- 실제 소리 자료 연결: 맹꽁이·옴개구리는 외부 원본 플레이어, 두꺼비는 출처를 표시한 CC BY 4.0 음원
- 번호 선택형 관찰 화면과 퀴즈 5개. 휴대폰에서는 한 친구씩 크게 표시
- 정답 설명, 오답 거품·화면 물방울 효과, 지원되는 기기의 진동, 효과 설정
- 게의 자절을 동물 보호와 연결하는 문제
- 서버가 계산하는 점수·풀이 시간, SQLite에 보관하는 공통 순위, 선택형 별명 등록·기록 삭제
- 관찰·설명·모델 로딩·일시정지 시간은 풀이 시간에서 제외
- 앞 카메라, 기기 내 어깨 추적, 직접 배치 보조, 3D 캐릭터 합성·PNG 저장·지원 기기 공유
- 화면과 사진에 `상상아트 | 기획·제작 이미숙` 표시

## 모델

`app/assets/models/`에 실제 GLB 4개를 제공합니다. 모두 직접 구성한 **형태 시제품**입니다. 실제 개체 스캔이나 선택한 이미지의 최종 3D 재현본은 아닙니다. 앱은 같은 `models.mjs`의 메시를 생성해 사용합니다.

| 파일 | 용도 | 삼각형 | 형식 검사 |
|---|---|---:|---|
| maeng-observation-prototype.glb | 맹꽁이 관찰 | 27,500 | 오류 0 · 경고 0 |
| toad-observation-prototype.glb | 두꺼비 관찰 | 41,660 | 오류 0 · 경고 0 |
| om-observation-prototype.glb | 옴개구리 관찰 | 30,212 | 오류 0 · 경고 0 |
| mascot-seven-prototype.glb | 셀카 캐릭터 | 29,824 | 오류 0 · 경고 0 |

맹꽁이는 각 앞발 4개·뒷발 5개 발가락과 뒷발의 부분 물갈퀴를 구성했습니다. 셀카 모델에는 눈 깜빡임·울음주머니 애니메이션도 내보냈습니다. 생태 검수와 조형 보정은 남아 있습니다.

타깃 그림은 `app/assets/mascot-reference.png`로 고정하고 별도 3D 검토 화면에 함께 표시합니다. 일반 관객의 체험 시작 화면에는 타깃 그림을 보여주지 않습니다. 퀴즈 완료 뒤 셀카 캐릭터가 나옵니다. 그림의 발은 형태 근거로 사용하지 않으며 실제 구조에 맞춰 수정합니다.

기존 안내 게는 `assets/crab/`에 웹용 약 3.44 MB와 상세 약 10.77 MB GLB로 보관합니다. 현재 게는 정적 모델이며 눈자루·집게발 움직임은 없습니다. 거품·물방울은 웹 화면 효과입니다.

## 순위와 배포

- 기본 데이터베이스: `data/records.sqlite3`. Git에서 제외합니다. `SONGDO_DB`로 경로를 지정할 수 있습니다.
- 같은 서버를 이용하는 관객끼리 순위를 공유합니다. 한국 시간 기준, 정답 수 내림차순·풀이 시간 오름차순입니다.
- 기록은 30일, 체험 세션은 24시간 유지됩니다. 정리는 서버 시작과 새 체험 시작 시 수행됩니다.
- 현재 세션이 유지되는 동안 본인 기록 삭제가 가능합니다. 새 체험을 시작하거나 쿠키가 사라지면 이전 기록을 이 화면에서 삭제할 수 없습니다.
- 사진·영상은 업로드하지 않습니다. 별명·점수·시간과 세션 식별자만 서버에 저장합니다. 실명 입력을 요청하지 않습니다.
- `app/`만 정적 호스팅하면 **순위 없는 연습 모드**를 사용할 수 있습니다. GitHub Pages만으로 공통 SQLite 순위 서버는 실행되지 않습니다.
- 공통 순위 공개 운영에는 지속 저장소와 HTTPS가 있는 서버, 백업·운영 점검이 필요합니다. 현재 구현은 체험용이며 경품 경쟁을 위한 부정 참여 방지 시스템은 아닙니다.
- GitHub에 자료를 올린 것은 공개 사이트 배포 완료를 의미하지 않습니다.

## 검증과 남은 작업

확인: GLB 형식 검사, 브라우저의 관찰→5문제→결과→셀카 시작 화면, 서버 점수 계산·중복 제출 차단·순위 조회/삭제·비공개 경로 차단 통합검사 2개 통과.

미확인/미완료: 실제 휴대폰 카메라·어깨 추적·촬영 저장, 실제 음원 재생과 종별 음원 검수, 현장 성능, 7번 이미지와 일치하는 최종 조형, 생태학적 형태 검수, 게의 관절 애니메이션. 셀카의 사람과 캐릭터 사이 가림 처리는 구현하지 않았습니다. GPS 미션·인생네컷은 이번 맹꽁이 첫 체험 범위에 넣지 않았습니다.

## 제작 및 검사 명령

```sh
python tests/test_server.py
pnpm --dir tools install --frozen-lockfile
node tools/export-amphibians.mjs
node tools/build-crab.mjs "/path/to/original-crab.glb"
```

마지막 두 명령은 모델 파일을 갱신합니다. 원본 게 GLB와 개인 셀카는 저장소에 포함하지 않습니다. `tools/node_modules`는 모델 제작 시에만 필요하며 앱 실행에는 필요하지 않습니다.
